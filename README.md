# Eko Patrola

A web application for reporting illegal waste dumps and tracking cleanup actions in local communities.

## Tech Stack

- **Frontend** — React (Vite)
- **Backend** — Node.js + Express
- **Database** — MongoDB (Atlas)
- **Map** — Google Maps API

## Project Structure

```
eko-patrola/
├── backend/    # Express API, MongoDB models and routes
└── frontend/   # React client
```
